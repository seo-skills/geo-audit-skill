# Sample reports

Two copies of one report, as `geo report` writes them:

- [`client-report.html`](client-report.html) - the copy that gets sent. Open it in a browser.
- [`operator-report.html`](operator-report.html) - the same report plus the provenance an
  agency keeps: run id, evidence hash, crawl settings, failed pages, every signal.

Both are generated from the synthetic fixture site the test suite crawls, never from a
real one, so no one's content or data is redistributed. That site is built to be
imperfect - a page that only renders with JavaScript, a broken link, a JSON endpoint -
so the report has something to say. It is ordered for a publisher to show what
`--site-kind` adds.

They are regenerated by `python tools/gen_docs.py` from the audit's golden envelope,
and CI fails when they fall behind the code.
